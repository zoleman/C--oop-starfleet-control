# C--oop-starfleet-control

## Description  
`C--oop-starfleet-control` is a C# console application (object-oriented) that simulates management and control of a “starfleet” — a fleet of ships (or units). The project focuses on applying OOP principles (classes, composition/inheritance, encapsulation) to model ships, fleets, commands and fleet operations. Think of it as a sandbox to practice designing data structures and business logic in C# while simulating a “star-fleet control” system.

## Scope  
- While learning programming and object-oriented design, this project gives you a hands-on exercise in modelling real-world concepts (ships, fleets, commands) using OOP.  
- It helps to understand how to structure classes, relationships and logic in C#, reinforcing coding discipline and design thinking.  
- Projects like this build intuition for larger systems — good practice if planning to build more complex applications later.  
- Experience writing console applications, managing program flow, and testing logic via manual runs — a good stepping stone before web/GUI or more advanced projects.

## Prerequisites  
- .NET SDK / C# compiler (version compatible with your project — whatever you coded the project with)  
- A shell / terminal or an IDE (e.g. Visual Studio / Rider / VS Code with C# support) to build and run the project.  
- It’s a plain console project — no special external dependencies required besides .NET runtime.

```bash
